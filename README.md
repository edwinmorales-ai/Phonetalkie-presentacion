# Phonetalkie

**Habla con tu grupo desde el navegador, como con un walkie-talkie.** Crea una sala, invita a otras personas y mantén pulsado el botón para transmitir tu voz.

### Prueba la aplicación

**[Abrir Phonetalkie](https://phonetalkie-edwin.aibuilder00.chatgpt.site)**

1. Abre la web y crea una sala o entra con el código que te compartan.
2. Comparte el enlace, el código o el QR con tu grupo.
3. Permite el uso del micrófono y mantén pulsado **Hablar** cuando sea tu turno.

Las salas admiten hasta cuatro personas. Solo una puede hablar a la vez y cada turno dura como máximo 60 segundos. La voz se transmite en directo; la aplicación no graba las conversaciones ni ofrece un historial de audio.

Puedes usarla desde el teléfono sin instalar una app. Mantén la página abierta y el teléfono activo durante la conversación: el audio en segundo plano depende del navegador y del dispositivo.

Este repositorio es la presentación pública del proyecto. El código fuente se mantiene en un repositorio privado.
